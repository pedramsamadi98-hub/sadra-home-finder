# Default category cover images

One image per key in `src/lib/default-covers.ts` (`DefaultCoverKey`).
Upload each real file with `lovable-assets create --file <img> --filename <key>.jpg > <key>.jpg.asset.json`.
Pointers named `<key>.<ext>.asset.json` are picked up automatically. Never store these in property photos.
