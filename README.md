# Sadra Property Hub

Build a modern Persian real estate property management web app for a real estate agent in Sadra, Shiraz, Iran.

The app must be fully RTL and in Persian.

Main features:

- Add, edit and delete property listings

- Property types: apartment, villa, land, commercial property

- Fields: property type, transaction type (sale/rent), location, neighborhood, area, price, bedrooms, floor, building age, parking, elevator, storage, owner name, owner phone number, description and notes

- Upload and display multiple property photos

- Search properties quickly

- Filter by property type, sale/rent, neighborhood, area, price and number of bedrooms

- Dashboard showing total active listings, sold/rented listings and recent listings

- Clean mobile-first design because I will mainly use it on my Android phone

- Persian numbers and Persian date format where appropriate

- Make the interface simple, fast and professional

- Use a dark/light modern real estate dashboard style

- Include sample property data so I can test the app immediately

Do not create a presentation. Build the actual working web application.
